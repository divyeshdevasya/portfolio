## Presentation and source

This repository publishes case studies and the static portfolio website. Application implementation, project data and internal material remain private. Diagrams are original conceptual illustrations, not employer screenshots. Each case study distinguishes demonstrations, research and professional work.

The website uses plain HTML and CSS, with no build step or external runtime dependencies. `index.html` is the entry point; `projects/` holds matching web and Markdown case studies; `assets/` holds the styles and diagrams.
