01 / Backend · Personal reference project

Distributed telemetry backend

A simulated-device system exploring how readings move from concurrent ingestion to durable storage and a live dashboard.

Simulated devices → Go ingestion → Spring Boot API → PostgreSQL

Bounded queues, batching, retries, duplicate handling, and monitoring. The central trade-off: throughput, latency, and behavior when downstream services fail.

02 / Applied ML · Master's research

Delivery availability prediction

Exploring next-zone prediction from home-relative movement sequences, comparing Markov, LSTM, and Transformer models.

Research emphasis: representation design, preprocessing, evaluation, and the trade-off between predictive utility and privacy. A research prototype; production impact and independently verified privacy guarantees are not claimed.

Deep Spatio-Temporal Learning with Anonymity Guarantees
